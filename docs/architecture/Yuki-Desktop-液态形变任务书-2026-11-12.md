# Yuki Desktop 液态形变任务书

日期：2026-11-12

状态：用户问「所以做的够好够液态玻璃了吗」，得知最大差距是形状不会像液体一样变形后要求「把第1条也做了，单开PR」；施工中又要求「命令面板也可以做」「边缘色散我希望你能找到一个开销最小的解法……蓝色按钮也统一一下效果吧」（M4–M6）。本任务书即执行依据，基线为液态玻璃统一 PR（#62）。

## 1. 目标与原则

让玻璃像液体：按下的按钮鼓起并被指针牵引，菜单和弹出层从触发它的按钮里长出来、关闭时缩回去，弹出的玻璃与按钮的玻璃在形变中连成一体。

- 禁止防御性编程：所有形变由仓库已有的弹簧（`motion/spring.ts`）逐帧采样驱动，与发送水滴同一套做法，不引入动画库；不新增状态机。
- 「减少动态效果」时不形变：按钮不缩放，弹出层直接出现与消失。
- 操作从不等动画：按钮点击、键盘操作、焦点归还都与现在相同时刻发生；关闭动画只延后视觉上的消失。

## 2. 调研基线

| 项目 | 现状 |
| --- | --- |
| 按钮按压（`usePress`） | 按下缩小到 0.985（图标按钮 0.965），附按压点高光；不随指针移动 |
| 对话框（`Sheet`）、命令面板 | CSS `sheet-enter` / `palette-enter`：从 0.965 放大并淡入，与触发按钮无关；关闭瞬间消失 |
| 角色切换菜单（`RoleSwitcher`） | 白底加描边，不是玻璃（上一 PR 的盘点遗漏）；出现与关闭都是瞬间 |
| 分段、开关、滑杆滑块 | 已随速度拉伸、按压时鼓起，保留 |
| 原生菜单（右键、应用菜单） | 由系统绘制，网页无法形变，不在范围 |

## 3. 施工项

### M1 按钮液态按压
按下时鼓起（图标按钮 1.08、文字按钮 1.03，触控再大一些），按住移动时朝指针方向被牵引并沿该方向拉长，越过按钮边缘照旧取消；松开以弹簧回弹。

### M2 弹出层从按钮长出
`motion/emerge.ts`：记录最近一次按下的按钮；弹出层打开时若由它触发，就从它的位置与圆角出发，平移加缩放成完整面板，缩放过程中按比例修正圆角，使任何时刻都是正常圆角矩形；弹簧略过冲后回稳；面板内容在形状接近完成时淡入。关闭时以不过冲的弹簧缩回原按钮后再真正关闭。没有触发按钮（快捷键打开）时从中心轻微放大。

- 对话框：打开与关闭都形变；角色切换（`active` 变化）导致的关闭仍立即关闭。
- 命令面板：打开形变；关闭时组件卸载，在卸载前的布局阶段由玻璃替身缩回（见 M4）。
- 角色切换菜单：改为玻璃（`card` 透镜），打开与关闭都形变。

### M3 玻璃连成一体
弹出层的玻璃从按钮的玻璃形状长出（M2），形变期间二者重叠为同一块；删除被取代的 `sheet-enter`、`palette-enter`。

### M4 命令面板关闭
命令面板的打开/关闭改在布局副作用中执行，卸载时元素仍在文档里，由同一玻璃替身缩回；回归页的命令面板改为真正关闭。

### M5 开销最小的边缘色散
实测（每轮约 240–300 帧，四块玻璃压在滚动文字上）：

| 做法 | 软件渲染（SwiftShader）平均帧时间 / 超 20ms 帧 | Apple M6（Metal） |
| --- | --- | --- |
| 现有单次折射 | 16.7ms / 0–1 | 60 帧，无掉帧 |
| 常规三通道（3 次位移 + 3 次通道分离 + 2 次合成），全部玻璃 | 30.1ms / 180 | 60 帧；16 块铺满窗口仍 60 帧 |
| 两次位移（红色多弯一点，绿蓝共用主弯折），全部玻璃 | 20.9ms / 55 | — |
| 任一做法只用于浮在滚动内容上的玻璃 | 16.7ms / 0（与不做相同） | — |

用户要求「色散按最好的方案去做……还有优化空间吗」。原两次位移方案让红色多弯，与真实玻璃相反（蓝光折射最多、红光最少），且只有红/青两色；而开销主要由「只用在哪些玻璃」决定：三通道只用于浮动玻璃时，软件渲染同样是 16.7ms。

采用：绿色沿用主弯折，红色少弯 12%、蓝色多弯 12%，各自取一个通道、保留透明度后以 screen 混合（通道不重叠，结果精确），边缘呈连续的红到蓝过渡；只给 `composer`、`toolbar` 两种透镜（输入框、只读提示条、工具按钮组、电脑画面工具列）。对话框、命令面板背后是模糊遮罩，卡片与气泡背后是平涂背景，色散无从显色，不做。

### M6 蓝色按钮的有色玻璃
用户先要求「蓝色按钮也统一一下效果」，又要求「重新研究一下，怎么做最好看」，看到渐变后说「我不喜欢底色莫名奇妙的渐变」。

比较了四种底色（六种角色主题色 × 浅/深主题截图并量白字对比度）：现状叠白色光泽偏粉偏灰；深色主题下浅粉底配深色字像糖果；半透明有色玻璃颜色发淡；同色相加深加彩、两主题都配白字最好看，但亮度不封顶时绿、青只有 3.6–4.4。

采用：主要按钮与发送按钮在两种主题下都是一块平涂的 `oklch(from var(--accent) min(l, 0.52) calc(c * 1.35) h)` 配白字（六种主题色两主题最低 4.70）；不用渐变，厚度只来自与透明玻璃同一套的光：左上亮的边缘、跟随指针的高光（共用 `--pointer-x/y`），加一圈同色投影；按下时加深 0.06；停用时不发光，强制色彩模式下去掉。

### M7 按钮间距与载入的液态展开
用户要求「检查一下按钮中的字间距以及一些边框大小间距的问题……载入那边在转圈圈，那个圈和字太紧密了，位置也不对，可以考虑按钮的两边扩大与缩小动画」「动画也请做的自然灵动的液态玻璃动画，像苹果那样」。

实测（组件展示页）：载入圈以绝对定位放在左内边距（left 4px、宽 10px），与文字只隔约 0px，且不参与居中；停用按钮去掉了描边，与同排按钮不像同一类；两字按钮宽 54.5px；有按钮继承外层 22px 行高；13px 中文字距为 normal，粗体时挤成一团（比较 normal / 0.02 / 0.04 / 0.06em 后取 0.03em）。

- 载入圈改为文字前的占位（12px 圈 + 6px 间距），占位宽度由 `--busy`（注册为数字）驱动，`springs.busy`（k 420、阻尼比 0.62，约 8% 过冲）逐帧采样：展开时按钮两侧像液体一样鼓出再回稳，收起时同样以弹簧收回；收起后抵消 flex 间距，不留空位；不显示时转圈暂停。
- 主要/次要按钮最小宽 64px（大按钮 80px），字距 0.03em，行高固定 18px（大按钮 20px），停用的次要按钮保留描边。

### M8 打开大面板不卡
CI（macOS 无显卡）上打开对话框出现 115ms 长任务，超过 `liquid-glass` 的 100ms 上限。本机 CPU 降速 6 倍复现为 52ms + 193ms。生成位移图与光照图时，整张图先填成中性值，只计算玻璃边缘与内辉光所在的一圈：避开四角的行只访问左右两侧边缘，玻璃外与边缘以内的像素不再求法线。13 种玻璃的位移图与光照图改前改后逐张一致；同条件下长任务降到 69–79ms。

## 4. 失败情形（先写，再写代码）

E2E `tests/e2e/liquid-morph.spec.ts`（组件展示页、角色切换页、回归页），逐帧暂停采样，产物 `liquid-morph.json`。

1. 按住图标按钮时缩放不大于 1.05，或按住文字按钮时不大于 1.02。
2. 按住后把指针移向按钮右侧，按钮没有向右位移；松开后仍留有缩放或位移。
3. 减少动态效果时按下仍有缩放或位移。
4. 由按钮打开的对话框第一帧的中心离按钮中心超过 4px，或大小与按钮相差超过 25%。
5. 任一帧对话框可见圆角（元素圆角乘以该帧缩放）与该帧应有圆角相差超过 1.5px。
6. 对话框没有过冲（全程最大缩放不大于 1.003），或最后一帧不是完整大小。
7. 对话框内容在第一帧可见（不透明度 > 0.05）。
8. 关闭时对话框最后一帧没有回到按钮处，或动画结束后对话框仍打开，或焦点没有回到按钮。
9. 快捷键打开命令面板时（无触发按钮）第一帧不在面板中心附近、缩放不在 0.9–1 之间。
10. 角色切换菜单不是折射玻璃，或打开第一帧不在切换按钮处，或关闭后菜单仍在。
11. 减少动态效果时对话框、菜单仍有形变动画。
12. 形变过程中按钮点击、Escape 关闭、焦点归还任一被延后到动画结束之后才发生（以操作计数与焦点检查）。
13. 命令面板关闭后没有缩回的玻璃替身，或替身动画结束后仍在。
14. 黑白折射样本两端没有强彩色像素（只有色散会产生），或玻璃上的红字像素因折射而移动。
15. 输入框的滤镜不是三次位移（绿、红、蓝），或气泡的滤镜不是一次。
16. 蓝色按钮底色不是平涂（有渐变），没有方向边缘或指针高光，停用的按钮仍发光，或任一主题色在任一主题下白字对比度低于 4.5。

17. 载入占位的展开没有过冲（`--busy` 最大值不超过 1.02）。
18. 静止时载入圈与文字间距小于 5px、左右内边距相差超过 2px，或圈与文字的垂直中心相差超过 1.5px。
19. 两字按钮窄于 64px、字距为 0、行高不是 18px，或停用的次要按钮没有描边。

13、17–19 在 `liquid-morph.spec.ts`；14 在 `control-motion.spec.ts`；15、16 在 `liquid-glass.spec.ts`。
