# Yuki Desktop 液态玻璃统一任务书

日期：2026-11-12

状态：用户要求「单开PR，全部升级成折射玻璃，按流程做完更新我本机」，并问「够不够像苹果的液态玻璃了」。本任务书即执行依据，基线为 #61（发送动画与玻璃方向光）合并后的 main。

## 1. 目标与原则

所有浮在内容上的玻璃面都用同一套折射玻璃，并补上与苹果液态玻璃差距最大的三项：边缘透镜的厚度感、随指针流动的高光、压住背景对比以保证文字可读。

- 禁止防御性编程：继续用现有 `useGlass`（SVG 位移图 + `backdrop-filter`），不新增第二套材质机制；不透明模式、强制色彩模式沿用现有关闭路径。
- 原生材质优先：macOS / Windows 侧边栏用系统原生窗口材质（vibrancy / Mica），背后是桌面，Chromium 无法采样折射；Linux 侧边栏背后是纯色。侧边栏不加折射，只统一边缘光方向。
- 不做：形状融合变形（工作量大，另案）、边缘色散（Chromium 中需按通道多次位移，滚动成本高）、真正按背景像素自适应底色（页面无法读回背景像素）。

## 2. 调研基线

基线：Desktop `feat/send-motion`（#61）。

| 玻璃面 | 现状 |
| --- | --- |
| 输入框、工具按钮组、开关/分段/滑杆滑块、对话气泡、工作卡片 | 已是折射玻璃（`useGlass`），#61 起边缘光有方向 |
| 配对页、本机 Bot 欢迎卡片（`data-glass="card"`） | 只有 `[data-glass]::before` 上亮下暗的均匀描边，无折射 |
| 对话只读提示条（`.readonly`） | `blur(28px)` 磨砂，无折射 |
| 关于页 `.toast` 样式 | 没有任何界面使用（死样式），`presets.toast` 也无人使用：两者删除，不升级 |
| 电脑画面浮动工具栏（`Computer.module.css .floating`） | 深色半透明 + `blur(20px)`，风格独立 |
| 对话框（`Controls.tsx` `<dialog>`）、命令面板 | 本体 `--mat-sheet` 0.97 近乎不透明，只有遮罩模糊 |
| 边缘高光 | 固定光照图，不随指针变化 |
| 背景对比 | 玻璃下内容原对比直接透出，滚动文字压在输入框下时干扰可读性 |

## 3. 施工项

### G1 全部浮层升级为折射玻璃
欢迎卡片、只读提示条、电脑画面浮动工具栏、对话框、命令面板接上 `useGlass`，各自用适合尺寸的预设；底色改为半透明并保留不透明模式下的实色。删除不再需要的独立磨砂写法。

### G2 边缘厚度
位移图沿用现有凸面轮廓（越靠外缘弯折越强，向内平滑归零），光照图在迎光边外缘一条细亮线之外加一条向内渐弱的内辉光，读出玻璃厚度。大尺寸玻璃按面积降低位移图分辨率，避免生成时卡顿。

### G3 随指针流动的高光
指针在窗口内移动时，只更新根元素上的两个 CSS 变量；每块玻璃的边缘光以固定定位的径向渐变为光源、以自身光照图为遮罩，靠近指针的边缘更亮。无需逐块玻璃运行脚本。

### G4 压住背景对比
折射玻璃的 `backdrop-filter` 统一加入对比与亮度压缩（浅色提亮、深色压暗），玻璃下的滚动内容不再与玻璃上的文字抢对比。

### G5 侧边栏
侧边栏边缘光改为与其他玻璃同方向（左上亮、右下弱），原生材质不变。

## 4. 失败情形（先写，再写代码）

E2E `tests/e2e/liquid-glass.spec.ts`（组件展示页与各界面回归页；回归页新增 `readonly=1` 打开 QQ 对话以显示只读提示条），产物 `liquid-glass.json` 与各界面截图。本机 Bot 欢迎卡片与配对卡片同一写法，无独立回归页。

1. 任一玻璃面（输入框、三种滑块、气泡、工作卡片、配对欢迎卡片、只读提示条、对话框、命令面板；电脑画面工具栏在真实电脑 E2E `computer-toolbar` 中检查）在透明模式下没有 `data-refracting` 或 `backdrop-filter` 不含 `url(`。
2. 不透明模式下上述任一仍有折射或半透明底色。
3. 任一玻璃面的光照图不满足：下边亮度 < 上边 0.6 倍、右边 < 左边 0.75 倍（均匀描边两者都约为 1；小滑块实测 0.48、0.51，留出跨平台余量）。
4. 光照图迎光边没有向内渐弱的内辉光（距外缘 3px 处亮度为 0）。
5. 指针移到玻璃边缘附近时，该处边缘亮度没有高于指针远离时。
6. 折射开关前后玻璃下的背景像素没有变化，或玻璃上的文字像素被移动。
7. 玻璃下背景的对比没有被压缩（同一背景条纹在玻璃内外的亮度差，玻璃内不小于玻璃外）。
8. 打开对话框或命令面板时出现超过 100ms 的长任务。
9. 侧边栏边缘不是上亮下弱。
