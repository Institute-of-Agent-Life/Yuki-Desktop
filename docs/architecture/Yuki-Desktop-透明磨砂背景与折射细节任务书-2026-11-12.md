# Yuki Desktop 透明磨砂背景与折射细节任务书

日期：2026-11-12

状态：用户问「还有提升空间吗，我认为我可以把整个背景改成透明磨砂+液态玻璃，依旧保留亮或暗的底层逻辑……背景的折射细节你有认真做吗」，并选择「先做成背景选项」。本任务书即执行依据，基线为 `feat/apple-light`（#66）。

## 1. 结论

| 事实 | 依据 | 处理 |
| --- | --- | --- |
| 窗口本身已是整窗系统磨砂（macOS vibrancy、Windows 11 mica），只是主面板涂了不透明底色 | `window-appearance.ts` 背景透明并设材质；`.main` 背景 `--bg-content` | 新背景「桌面」：主面板改为半透明本色（浅／深随主题），对话区不再铺实色 |
| 网页里的液态玻璃看不到系统磨砂层 | 折射与色散是对网页内背后内容做位移；系统磨砂在窗口外合成 | 在半透明之上叠一层淡的光线纹理，让玻璃仍有可弯折的结构；不做「完全透明」 |
| 没有系统材质或要求不透明时不能透明 | Linux 无材质；「永远不透明」、减少透明度、增加对比时 `data-material="none"` | 回退为纯色背景与不透明主面板 |
| 位移图分辨率偏低 | 气泡位移图上限每 CSS 像素 1 格，其余上限 2 格，不随显示像素比 | 上限改为显示像素比；大面板仍按「最长边 360／720 格」限制成本 |

## 2. 失败情形（先写，再写代码）

E2E：`chat-polish.spec.ts`、`settings.spec.ts`、`glass-quality.spec.ts`。

1. 选「桌面」且有系统材质时，主面板背景不透明（alpha ≥ 0.9）或完全透明（alpha ≤ 0.2），或对话区仍铺不透明背景。
2. 「桌面」背景下没有可供玻璃弯折的纹理层。
3. 没有系统材质、「永远不透明」或增加对比时，「桌面」仍半透明。
4. 「桌面」不在对话背景选项中，或重启后不保留。
5. 显示像素比为 2 时，窄气泡（最长边 ≤ 180px）的位移图不是显示分辨率。
6. 打开对话框产生超过 100ms 的长任务（原有用例保持）。
7. 深色下玻璃让背后变暗：纯色、光线、极光背景上，输入框内部比紧邻的外侧背景暗（用户：「输入框其实没必要变黑的，这个多余了」）。实测当前版本三种背景下输入框均略亮于外侧（27→32、47.5→48.5、46.4→49.8）；先前描述的「浅色输入框偏灰」是一般浏览器无系统磨砂时的模拟误差，真实 Electron 中不出现。此条作为护栏保留。

## 3. 施工中的判断

- 试过给输入框加 4% 整体透镜放大：框内格线与框外错开（两端约 14px），读起来像画面错位而不是透镜。苹果的放大集中在边缘、内部几乎不变，这已由现有边框带的弯折承担，故不采用。
