# Yuki Desktop 弹窗收放与回执弹窗任务书

日期：2026-11-12

状态：用户使用 #63 版本后提出：
- 「点击左上角那个Yuki头像的界面弹出后无法收回」；
- 「那个玻璃弹窗的算法有问题，会突然变透明」；
- 「全局的动画流畅度都一般，不知道有没有优化延迟了」；
- 「档案与成果的程式码右边有空出很大一块空隙，收进去一下」；
- 「大部分弹窗的气泡效果和窗口本身不一样协调，比如弧度不一样，大小不一样，像是更换头像的窗口和更正记忆的窗口，这两个特别严重」；
- 「查看原回执和查看终端回执这种功能按钮，点击了之后应该出现的是弹窗，而不是显示在最底下」。

本任务书即执行依据，基线为 `feat/chat-polish`。

## 1. 调研结论

| 问题 | 证据 | 处理 |
| --- | --- | --- |
| 角色选单收不回 | `role-switcher.html` 慢放：选单开着时再点头像，按下时焦点移到头像按钮，选单 `onBlur` 判定焦点离开而关闭；随后的 click 又把它切成打开，出现新的选单（`yuki-glass-2`），同时旧选单的残影在收回 | 失焦只在焦点离开整个切换器（含头像按钮）时关闭，头像按钮的 click 负责收起 |
| 玻璃弹窗突然变透明 | 同一录像：收回中的残影 `--refract` 为空、没有光照图。卸载时 `useGlass` 的清理先于收回执行，先移除了折射与光照，残影一出现就从带折射、有边光的玻璃变成只有模糊的平板；若又被重开，就是一闪 | 收回在玻璃清理之前量取并复制外观；残影带着自己那份滤镜副本，与残影一同移除 |
| 弹窗收回时大小、弧度对不上 | 「更正记忆」：父组件在同一次更新里把 `open` 改为假并清空内容，弹窗先缩成 197px 高（打开时 321px），收回才量取尺寸，残影比原窗口小一截。「更换头像」：整个 `Sheet` 被卸载，没有收回动画，窗口瞬间消失 | 关闭中的 `Sheet` 保留它显示过的标题、内容与按钮，直到收回量取并关闭后才换成父组件当前的内容；卸载时若仍打开，同样先收回 |
| 动画流畅度 | 更换头像弹窗打开（2 倍像素、软件合成）：每次 10–33 帧超过 20ms、最长 50ms，没有超过 50ms 的长任务。逐项关闭：去掉遮罩 `::backdrop` 的 `blur(8px)` 后几乎不掉帧；去掉折射、圆角动画或弹窗自身模糊，影响都很小。原因是弹窗玻璃每帧要读取一层全窗口模糊后的结果，两层背景滤镜叠加重算 | 删除对话框与命令面板遮罩的模糊，只保留变暗；删除随之无用的 `--blur-scrim` 与不透明模式里对它的覆盖 |
| 「程式碼」右侧空隙 | 成果列表顶部把分段控制拉满整栏，按钮保持自身宽度，多出的空间全落在最后一个按钮右侧 | 分段按钮平分多出的宽度；未被拉伸的分段控制不变 |
| 同类问题复查（用户：「刚刚出现的问题或许并非个例」） | 全部玻璃弹窗只经 `Sheet`（23 处）、命令面板与角色选单三条路径，上述修正覆盖全部；应用菜单是系统原生菜单；其余「查看…」按钮本就开弹窗或跳转，只有两个回执把详情追加在页面底下；全窗口模糊遮罩只有对话框与命令面板两处 | 一并处理，无遗漏 |
| 彩边不显著、浮动玻璃过雾（用户：「彩边没有显示与玻璃质感优化的问题解决过了吗……不会出现过多模糊和毛刺了吗」） | 2 倍像素放大输入框：边缘光按显示像素绘制并抗锯齿，弧线无台阶；但格线经 `blur(2px)` 与 28%／36% 底色后几乎看不见（格线对比：浅色 4、深色 2），彩边被抹成淡色晕染（红蓝分离 18）。比较 0.5px、1px 两组：0.5px 出现刺眼的彩虹条纹；1px 配浅色 16%、深色 24% 底色时格线对比升到 9／5，红蓝分离 26。工具栏胶囊停在不透明的标题栏上，下面没有可折射的内容，调参前后无差别，不改 | 输入框与只读提示栏改为 `blur(1px)`，底色浅色 16%、深色 24% |
| 沙箱与 QQ 的切换不好看（用户：「Yuki沙箱和qq切换的那个按钮，能不能做的好看点」） | 「電腦」页标题处是系统原生下拉菜单（「顯示器 ▾」），与其余玻璃控件不一致，只有两个选项却要先展开 | 改为分段控件（与成果类型同一组件，玻璃滑块），两项「{名字} 的沙箱」「QQ 登入」直接可点；方向键切换并保持焦点；不改切换后的接手、交回与连线行为 |
| 弹窗外一圈不搭的边框（用户：「UI底部与玻璃效果不重合导致外面有一圈不搭的边框……主要是弹窗会出现的问题」） | 真实 Electron（GPU、2 倍像素）放大四角：命令面板顶部搜索框聚焦时的内框是直角矩形，被面板圆角截断，沿面板外缘形成一圈弧度不同的框；输入框聚焦时外扩 3px、隔 1px 的焦点框与玻璃之间露出一道缝；对话框、命令面板、角色选单的阴影都带 0.5px 描边，不随光照，背光的底边也亮；输入框另有一条内阴影亮线与光照图重复。另：无头浏览器在 2 倍像素下大模糊会在右下留一条未模糊的带，真实 Electron 中不出现，属软件合成假象，不处理 | 玻璃的形状只由光照图与阴影给出：一般模式下删去这些线；增强对比时焦点以贴着玻璃边缘、随圆角的线表示（输入框整体、面板搜索框下缘），不外扩也不被截断 |
| 回执显示在页面最底下 | 「查看原回执」「查看终端回执」把详情追加在列表下方，需要滚动寻找 | 详情改为弹窗（`Sheet`），标题保持「原操作 …」「原終端執行 …」；需要文字的「排入原會話」「調整原任務」在弹窗内提供同一份文字输入 |

## 2. 失败情形（先写，再写代码）

E2E：`liquid-morph.spec.ts`、`popup-polish.spec.ts`（新）、`local-computer.spec.ts`、`agent-connector.spec.ts`、`artifacts.spec.ts`（第 6 条）、`glass-quality.spec.ts`（第 8、9 条）。

1. 角色选单打开时再点头像，选单仍在或再次出现。
2. 收回中的残影没有光照图，或背景滤镜引用的折射滤镜不存在。
3. 「更正记忆」关闭时，残影起始尺寸不等于打开时的弹窗尺寸（±1px）。
4. 「更换头像」关闭（组件卸载）时没有残影，或残影起始尺寸不等于打开时的尺寸。
5. 对话框或命令面板打开时，遮罩有背景滤镜。
6. 成果类型分段控制被拉伸时，最后一个按钮右缘离控制内缘超过 2px。
7. 点「查看原回执」「查看終端回執」后详情不在对话框里；关闭对话框后焦点没有回到原按钮。
8. 格线背景上，透过输入框空白处的格线亮度差浅色低于 6、深色低于 4（修改前 4／2）。
9. 输入框上缘弯折带里红、蓝通道的最大差值低于 22（修改前 18）。
11. 一般模式下，对话框、命令面板或角色选单的阴影含不透明的描边环；命令面板搜索框聚焦时有外框或内框；输入框聚焦时有外扩的焦点框或内阴影亮线。增强对比时输入框聚焦没有贴边的焦点线，或命令面板搜索框聚焦时下缘不是强调色（`popup-polish.spec.ts`）。
10. 「電腦」页的显示器切换仍是下拉菜单，或不是含「{名字} 的沙箱」「QQ 登入」两项的单选组；方向键不能切换，或切换后焦点离开所选项（`snowluma-display.spec.ts`）。
