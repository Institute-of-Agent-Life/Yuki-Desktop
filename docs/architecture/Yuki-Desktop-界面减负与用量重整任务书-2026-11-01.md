## 1. 目标与原则

让普通用户看懂「正在用什么、这段时间用了多少、工作完成后到哪里拿结果」。优先删除重复展示和失去用途的入口，不通过增加说明、状态、兼容层或另一套面板包住旧问题。

- 禁止防御性编程；沿既有身份、授权、原请求 UUID、revision/CAS、工作与产物合同，不新增角色、门槛、重试、经验阈值或辅助状态。
- 当前配置、已发生的模型调用、工作状态和平台送达回执分别认原事实。修改展示不重写历史，不把调用成功或文件送达提升为 Work 完成。
- 减少用户可见的复杂度，不删除真实能力、已保存参数、密钥、历史调用、文件、产物版本或引用。
- 复用现有组件、路由和持久化。只读统计使用现有 `model_invocations`，不另建用量账本、历史名称注册表或持久聚合缓存。
- 本机自动测试全部后台运行：`YUKI_E2E_BACKGROUND_WINDOWS=1`。不接管真人界面，不改真实 profile、Connector、native 登录、服务地址或生产数据。

## 5. 用量产品方案与 Demo

本轮交互 Demo 用明确标注的示范数据，不访问生产、不携带密钥，也不冒充供应商账单。先供用户检查审美、密度和交互；视觉方向未确认前不替换正式页面。

### 5.1 默认信息层次

1. 顶部只有「用量」和时间范围，默认「今日」。首期提供「今日／近 24 小時／近 7 天／全部留存」，明确显示实际起止时间与时区。
2. 一个主要的「已回報 Token」数字；旁边/下方低强调显示输入、输出、调用次数与缓存读取数量及占输入比例。
3. 同一处切换「模型／用途」，一次只呈现一种列表。模型以真实模型名为主、供应商为次行；每行默认只显示 Token、占比和调用次数，适当的比例条辅助阅读。
4. 选中一行才展开输入、输出、缓存、失败、未知用量及原配置来源。筛选后摘要、列表、占比使用同一结果集；页面写明「篩選結果」，不能仍混入全局数字。
5. 未报用量大于零才显示简短提示；详细口径折叠。正常页不常驻成功/失败诊断、平均延迟、5m/1h 缓存写入等整排技术列。
6. 空数据、读取失败、加载和未知用量分别呈现；失败不显示零用量，切时间时不把上个范围数字贴成新范围。

窄栏验收测的是用量内容的实际可见宽度，保留既有 Desktop 设置导航；不把 360px 整个窗口被侧栏裁切的截图当作 360px 内容栏通过。记录窗口视口、内容栏与父容器的真实边界和平台滚动条宽度，本轮不重做手机端导航。

Demo 对比「用量總覽」与「精簡卡片」两种布局，内容和统计口径相同。布局选择不产生产品配置；正式实现收敛为用户确认的一种。

### 5.2 数字与统计事实

- 时间以完整起止 `[start, end)` 查询；今日按页面采用的明确时区从零点开始，近 24 小时/7 天为滚动窗口，全部留存明确标注不代表完整生命周期。
- 沿现有 `model_invocations` 的原始 task/provider/model/profile_id/usage/created_at 记录查询。不能用当前 routes 或当前 Profile 给过去补模型名、供应商或用途。
- summary 和 breakdown 从一次一致读取的同一范围、同一筛选结果聚合；不分别查询再凑摘要。
- 模型组按 `(provider, model)`，不同供应商同名模型分开；相同实际模型的多个 Profile 可汇总，但来源详情保留原 Profile。配置或路由改名不拆改旧记录。
- 总 Token 使用原记录已报告的 `total_tokens`。输入、输出、缓存各按已知字段求和；缺失不变成零用量事实，不为补齐数据重发模型请求。
- Yuki 适配器已有规范化输入口径：例如 Anthropic 把未缓存输入、缓存读取和缓存写入合成输入量。缓存读取是输入的一部分，不能再加进总 Token。比例仅在已知输入/缓存字段的相同样本上计算，并显示覆盖口径；不平均各行百分比，不把缺缓存字段的调用当未命中。
- 未报告总量的调用仍计调用次数，并独立报告数量；有已知部分用量时仍保留，不用未知调用抹掉已知字段。
- 延迟沿已存在的统计口径，在需要时展开；不能标成首 Token 延迟或用户完整等待时长。
- 历史退役用途仍计入范围合计；可归入「歷史用途」并在详情保留原标签，不能默默过滤掉。`web_search` 当前仍记录，显示「聯網搜尋」。
- 不显示费用、节省金额、余额或额度推测；无真实价格与计费合同就没有这些数字。

## 7. 先写明失败场景，再施工验证

沿现有真实参考后端和 Electron E2E，验证匹配改动风险，不新增镜像实现细节的单元测试。Demo 的本地检查与正式真实后端验收分开记录。

1. 长中文标题、长英文文件名、无空格长 ID，320/360/760/1024px：状态完整单行、与标题不重叠、不被裁切；标题可省略且能查看全文。
2. 已完成、运行、待回答、失败、未知状态：维持原语义与动作；删除预览不删除待回答的问题。
3. 聊天不重复列工作产物；从原消息、工作详情与 Files 仍能打开原产物。同名不同 ID、同 ID 不同版本、重复发送引用保留原身份。
4. 简化表单只编辑模型名时，未碰的 wire/headers/思考/预算/搜索/能力字段原值不变，Key 不回显；原 revision、UUID、未知结果核对与授权断言保留。
5. 今日跨零点、滚动 24h、跨重启留存、全部留存：实际边界正确，摘要/分组/占比一致；时间切换不冒用旧数字。
6. 同一 Profile 曾换 model、多个 Profile 使用同一 model、同名 model 不同 provider：按调用当时来源正确分组。
7. planner/pro/flash 等历史来源保留累计；当前配置不复活旧枚举。历史来源进入明细后，合计不减少。
8. 缓存全已知、部分缺失、输入为零、只有缓存读取/写入、未报总量但有部分字段：不双计、不伪造零、不产生无定义百分比，覆盖信息真实。
9. API 错误、无数据、普通用户 403、撤销超管/设备后更新：不泄漏配置/私有资料，不把失败当零统计，不以隐藏 UI 代替执行处授权。
10. 默认屏幕无 profile UUID、迁移后缀或未知英文列堆叠；详细来源仍能追溯原配置，不重写账本。
